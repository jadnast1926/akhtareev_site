
Адаптивный одностраничный сайт-воспоминание о самых ярких моментах лета 2026 года. Проект выполнен с использованием современных практик веб-разработки и чистой архитектуры.

**Архитектура БЭМ:** Верстка полностью переписана по методологии БЭМ (Блок, Элемент, Модификатор) для легковесного CSS и удобной поддержки.
**Динамическая смена темы:** Реализовано переключение между светлым и темным режимами оформления с сохранением стилей через CSS-переменные.
**Интерактивный слайдер:** Кастомная фотогалерея на чистом JavaScript с защитой от спам-кликов во время анимации.
**Плавный скролл:** Нативная плавная навигация между экранами сайта.
**Анимация при скролле:** Элементы интерфейса плавно появляются при прокрутке страницы.
**Полный адаптив:** Сайт оптимизирован под любые устройства (мобильные телефоны, планшеты и десктопы).
