**Отличия:**
* **Живая смена дня и ночи:** В Figma день и закат нарисованы отдельно. На сайте они переключаются кнопкой-солнцем прямо на лету.
* **Плавное появление при скролле:** При прокрутке страницы блоки и карточки красиво выплывают снизу. В макете этого не увидеть, там всё статично.
* **Рабочая галерея:** В макете просто одна картинка. В коде сделан полноценный слайдер на 12 фото, которые плавно затухают при переключении.
* **Плавный переход по меню:** При клике на меню страница плавно прокручивается к нужному блоку, а не прыгает резко.
* **Ламповый шрифт:** Вместо обычного стандартного шрифта подключен красивый моноширинный шрифт `Iosevka Charon Mono`.
